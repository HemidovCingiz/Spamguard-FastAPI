# 🚨 SpamGuard – AI-Powered Spam Detection API

A modern, fast, and scalable **spam detection system** built with FastAPI.  
Designed to analyze messages in real time and determine whether they are spam or not.

> Goal: **Analyze messages instantly. Block spam. Keep systems clean.**

---

## ✨ Features

- ⚡ High-performance backend powered by **FastAPI**
- 🤖 Rule-based spam detection logic (ML-ready architecture)
- 🧠 Real-time message analysis
- 🌐 Clean and minimal frontend interface
- 🔌 API-first design (easy to integrate with any frontend)
- 📦 Scalable structure for future ML model integration

---

## 🏗️ Tech Stack

**Backend**
- FastAPI
- Python 3.11+
- Uvicorn

**Frontend**
- HTML
- CSS
- Vanilla JavaScript
